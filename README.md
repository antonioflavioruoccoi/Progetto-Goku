# Provaquiz

[Apri il gioco](https://provaquiz-pokemon-antonio.tangyember2.chatgpt.site)

Il sito è privato: accedi con l'account ChatGPT proprietario, se richiesto.
Premi **Gioca** per iniziare e avviare la musica.

Per eseguirlo in locale, avvia `python -m http.server 8000` dalla cartella
della repository e apri http://localhost:8000. Non aprire direttamente
`index.html`: il caricamento del Pokédex richiede un server HTTP.
