# Flag assets

The 82 local SVG flags in `web/assets/flags/` (one for each country in `data/population-countries.json`; the first 20 were added with the fixed pairs, the other 62 on 23 November 2026 from the same commit, unmodified) were taken from [`hampusborgos/country-flags`](https://github.com/hampusborgos/country-flags) at commit [`c09927e63705529bbf59ca6684cd9b23225dddad`](https://github.com/hampusborgos/country-flags/tree/c09927e63705529bbf59ca6684cd9b23225dddad). The repository README says the files are accurate country-flag renders sourced from Wikimedia Commons and that flags are in the public domain / not under copyright. The README also notes that a country's laws may impose restrictions on flag use; the assets are used here only to identify countries in a quiz. No remote image service or emoji font is required at runtime.

Filenames use lowercase ISO 3166-1 alpha-2 / GENC-2 codes carried in each population record (`iso2`). Country names remain visible text beside the decorative images, so a missing image never leaves only a two-letter code for a player or host. Each flag image has empty alternative text because the adjacent country name supplies its accessible label.

The quiz shows every flag inside the same fixed 3:2 frame with `object-fit: contain`, a neutral background and a thin border, so flags with different native proportions (for example Nigeria 2:1 and Brazil 10:7) are not shown at different visual sizes.
