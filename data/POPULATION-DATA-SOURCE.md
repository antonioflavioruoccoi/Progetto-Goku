# Population comparison data

`population-comparisons.json` keeps the ten original country pairs and their indices. The names and three-letter internal IDs stay stable; each record also has a two-letter GENC code for its local flag asset.

Population figures are U.S. Census Bureau International Database (IDB) total-population values for **July 1, 2025** (`YR=2025`, `POP`) from the **November 2026 IDB release**. The Census Bureau says IDB population size is available for July 1 of each calendar year, and that the IDB contains total population and demographic estimates/projections for countries and areas. Source pages: [IDB overview and methodology](https://www.census.gov/programs-surveys/international-programs/about/idb.html), [IDB API and variable documentation](https://www.census.gov/data/developers/data-sets/international-database.html), and [IDB country/area codes](https://www.census.gov/programs-surveys/international-programs/about/idb/countries-and-areas.html).

To avoid the API key required for individual API queries, this subset was extracted from the Bureau's bulk archive, [`idbzip.zip`](https://www.census.gov/data-tools/demo/data/idb/dataset/idbzip.zip), specifically `idb5yr.txt` (`POP`, filtered by `YR=2025` and the GENC country code in `GEO_ID`). The downloaded archive's SHA-256 was `d6c64e0a0dbfb3ae8e3c819476a043b9844ea3c2c30b92d53a305ec6f6eb5cff`. Its bundled `readme.txt` identifies it as the November 2026 release and describes the files as pipe-delimited Census API data. Population pairs and their order are intentionally unchanged from the 2019 version for stored-room compatibility; 2025 comparisons can therefore have a different winner.

The Census Bureau is a U.S. federal agency. Its IDB is a federal statistical product; federal employee works prepared in official duties are not subject to U.S. copyright under [17 U.S.C. §105](https://www.copyright.gov/title17/92chap1.html). The IDB methodology uses many source records, so this file redistributes only the published aggregate estimates and country identifiers, not underlying survey or census records. The Bureau identifies the IDB as population estimates and projections based on its evaluation of census, survey, administrative and vital-statistics sources.

`population-comparisons-2019.json` is kept as a compatibility snapshot for culture rooms created before the 2025 upgrade. Those rooms have no `population_year`; the Worker continues to reveal and score them with the original 2019 Natural Earth values. New rooms store `population_year: 2025`.

The historical snapshot came from Natural Earth **Admin 0 – Countries**, scale 1:110m, release v5.1.1: [source GeoJSON](https://raw.githubusercontent.com/nvkelso/natural-earth-vector/v5.1.1/geojson/ne_110m_admin_0_countries.geojson). Natural Earth says its vector and raster data are in the [public domain](https://www.naturalearthdata.com/about/terms-of-use/). The snapshot originally used `ADM0_A3`, `NAME_IT`, `POP_EST`, and `POP_YEAR`; the two-letter flag codes were subsequently added without changing country IDs, pair membership, or order.
